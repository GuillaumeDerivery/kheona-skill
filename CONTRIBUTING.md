# Contributing

Issues and PRs are welcome.

- The first line of an issue or PR says it all; anything more goes in a "Details" section.
- Run `bash test/run-all.sh`.
- Nothing here names anything outside this repository: use `owner/repo`, `example-cluster`, `111122223333`.
- Third-party actions are pinned by commit SHA.
- By contributing you agree your work is licensed under MPL-2.0.
